# vpn2 panel gate

С 2026-10-07 страница входа `https://vpn2.sharpmaind.ru/` и `https://vpn2.sharpmaind.ru/mtpanel/` не открываются без пароля Caddy. Браузер спрашивает логин до формы Remnawave.

Логин: `andrei`. Пароль лежит только на сервере в `/root/creds/vpn2-panel-gate.txt` (mode 600). В git его нет.

Открыто без этого пароля, иначе отвалятся клиенты:

- `/vpn`, `/vpngrpc`, `/xh` — сам VPN
- `/api/*`, включая `/api/sub` — подписки и API панели. API по-прежнему требует свой Bearer-токен Remnawave

Тот же замок стоит на запасном входе `cf-front` (`:8080`), иначе панель читалась бы в обход 443. У `cf-front` выключен admin API, чтобы перезагрузка конфига не попадала не в тот Caddy: на хосте два процесса делят сеть и раньше оба слушали 443.

`awg.sharpmaind.ru` и `kuma.sharpmaind.ru` снаружи по-прежнему без этого пароля.

Бот смотрит живой ли `vpn2`: ответ 401 для него нормальный, это закрытая страница, а не падение. Файл на сервере: `/opt/vpn-bot/bot.py`.
