# Sveta, Скайнет, Петербург

Пользователь `Sveta` (id 5) сидела в `Default-Squad`. Подписка начиналась с `🇫🇮 Megafon- Финляндия` — WebSocket. По логу ноды она ходила только в `vless-main`, xHTTP не использовала. Клиент: Happ на iPhone 15 Pro Max.

Домашний Wi‑Fi Скайнета режет этот WebSocket. В общем скваде xHTTP был с ALPN `h2`, для Скайнета это тоже плохой первый выбор.

## Что сделано 2026-10-08

Сквад `Sveta-SkyNet` (`b52de567-f64e-4951-94f2-08689b9a3983`). `Sveta` снята с `Default-Squad`.

Шесть хостов только этого сквада, адрес `185.141.217.43:443`, SNI `vpn2.sharpmaind.ru`, без HTTP/2. Порядок с 2026-10-08: первым идёт её обычный профиль Мегафона, дальше профили с именем Скайнет.

1. 🇫🇮 Megafon- Финляндия — WebSocket, ALPN `http/1.1`, chrome. Тот же профиль, которым она пользуется постоянно. В названии нет Скайнета.
2. Скайнет packet-up — xHTTP, `http/1.1`, chrome
3. Скайнет packet-up FF — то же, firefox
4. Скайнет stream-one
5. Скайнет stream-up
6. Скайнет WS FF — WebSocket, `http/1.1`, firefox

Остальные хосты из сквада исключены. Проверка подписки Happ: 6 профилей, первый `🇫🇮 Megafon- Финляндия`. У Default-Squad по-прежнему 15 профилей. Сервер xHTTP в режиме `auto`, `packet-up` он принимает.

На iPhone обновить подписку в Happ. Дома на Скайнете, если Мегафон не идёт, выбрать **Скайнет packet-up**. Если не цепляется — `packet-up FF`, затем `stream-one`.
